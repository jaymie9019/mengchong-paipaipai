# 萌宠排排排

抖音直播同款玩法的网页小游戏：盲盒翻开 · 三只成组 · 清空通关。

## 打开方式

- 直接双击 `index.html`，用浏览器打开即可
- 或在本目录启动静态服务，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`

无需安装依赖，无构建步骤。

## 玩法

1. 棋盘上每列只能点**最上方**的方块
2. 点中的萌宠进入底部槽位（最多 7 格）
3. 槽位中任意 **3 只相同**萌宠会自动消除
4. 上方方块移走后，下方盲盒 `?` 会翻开
5. 清空棋盘即通关；槽位挤满且无法三消则失败

## 操作

- **重新开始**：重洗本关
- **提示**：高亮一个较安全的落子
- 通关后可点 **下一关**（类型更多、堆更高、盲盒更多）
